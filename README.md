# 淘宝店铺经营分析工作台

个人电脑运行的电商经营分析工具（Streamlit 单机 Web 应用）。

## 功能

- 仪表盘：销售额、订单量、客单价、退款率、毛利率、总利润总览
- 订单管理：Excel 导入 / 手动维护订单
- 商品管理：商品档案、毛利自动计算、库存预警
- 交易分析：按日/周/月趋势、退款分析、时段分布
- 商品分析：TOP 商品、利润贡献、类目分析
- SOP 流程管理：选品→上架→推广→复盘 标准流程跟进
- 数据管理：演示数据 ↔ 我的数据 切换

## 启动方式

```powershell
python -m streamlit run app.py
```

启动后浏览器自动打开，默认地址 http://localhost:8501

## 目录结构

- `app.py` — 应用入口与导航
- `views/` — 各功能页面
- `core/` — 数据存储与指标计算
- `data/demo/` — 演示数据（淘宝公开数据集）
- `data/user/` — 用户自己的数据（订单、商品、流程）
- `data/templates/` — Excel 导入模板
- `PRD.md` — 产品需求文档

## 数据说明

- 演示数据：内置淘宝公开行为数据集（真实购买行为/商品/类目/时间），金额与退款为合理模拟值，打开即可体验全部分析功能；导入公司 Excel 后即为真实金额数据
- 我的数据：导入公司/店铺 Excel 后自动切换，与演示数据互不覆盖
- 所有数据仅保存在本机，不上传、不联网

## 指标口径

| 指标 | 公式 |
|---|---|
| 销售额 | Σ实付金额（剔除退款） |
| 订单量 | 非退款订单数（按订单号去重） |
| 客单价 | 销售额 ÷ 订单量 |
| 退款率 | 退款订单数 ÷ 总订单数 |
| 毛利 | 销售额 − Σ(成本价×数量) |
| 毛利率 | 毛利 ÷ 销售额 |
