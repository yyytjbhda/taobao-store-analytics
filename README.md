# 🛍️ 淘宝店铺经营分析工作台

一个**开箱即用的电商经营分析工具**：用 Excel 导入店铺数据，自动完成交易分析、商品分析、营销 ROI、客户分层，并内置电商运营全流程（SOP）管理。个人电脑即可运行，也可一键部署上线用于简历展示。

> 面向电商运营 / 商业分析岗位的日常工作，作品以「懂业务 + 会分析 + 能落地」为设计目标。

---

## ✨ 功能总览（11 个页面）

| 模块 | 能力 |
|---|---|
| 开场页 | 全屏电影感欢迎页（视频背景 + 字符级入场动画 + 玻璃拟态按钮） |
| 仪表盘 | 销售额 / 订单量 / 客单价 / 退款率 / 毛利率 / 总利润一屏总览 |
| 订单管理 | Excel 导入（模板下载）、手动维护、筛选、详情查看 |
| 商品管理 | 商品档案、毛利自动计算、库存预警阈值 |
| 交易分析 | 按日/周/月趋势、退款分析、下单时段分布 |
| 商品分析 | TOP 商品、利润贡献（帕累托）、类目分析、价格带、滞销识别 |
| 营销分析 | 推广花费录入、ROI 计算、渠道效果对比 |
| 客户分析 | 复购率、RFM 客户价值分层 |
| 经营建议 | 规则引擎自动生成商品 / 营销 / 客户 / 经营四类可执行建议 |
| SOP 流程管理 | 选品→上架→推广→复盘标准流程，支持自定义模板 |
| 数据管理 | 演示/我的数据切换、数据质量检查、报表导出（Excel + PNG） |

**设计亮点**
- 深色电影感主题：玻璃拟态卡片、统一图表配色、中文字体优化
- 数据质量检查：缺失 / 时间 / 数量 / 金额 / 重复记录自动体检
- 一键生成中文经营报告：多工作表 Excel + 单页 PNG 可视化报告（可直接用于周报/月报）

## 🛠️ 技术栈

- Python + Streamlit（单机 Web 应用，无需前端开发经验即可运行）
- pandas（数据处理）、plotly（交互图表）、matplotlib（图片版报告）、openpyxl（Excel 读写）
- 图表统一深色主题，全中文界面

## 🚀 快速开始

```powershell
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动（Windows 双击 start.bat 亦可）
python -m streamlit run app.py
```

浏览器自动打开 http://localhost:8501 ，内置演示数据可直接体验全部分析功能。

## 📁 目录结构

- `app.py` — 应用入口与导航
- `views/` — 11 个功能页面
- `core/` — 数据存储、指标计算、数据质量检查、经营建议引擎、报表生成
- `data/demo/` — 演示数据（淘宝公开行为数据集，已处理为订单/商品/营销表）
- `data/user/` — 用户自己的数据（订单、商品、营销、流程，不入库）
- `data/templates/` — Excel 导入模板（运行时生成）
- `static/` — 静态资源（电影感背景图）
- `PRD.md` — 产品需求文档
- `RESUME.md` — 简历 / 面试作品说明

## 📊 数据说明

- **演示数据**：基于淘宝公开行为数据集生成（真实购买行为/商品/类目/时间，金额与退款为合理模拟值），打开即可体验；导入公司 Excel 后即为真实数据
- **我的数据**：在「数据管理」页导入公司 / 店铺 Excel，与演示数据互不覆盖、一键切换
- **数据安全**：所有数据仅保存在本机（演示数据除外），不上传、不联网
- **报表导出**：支持多工作表 Excel 与单页 PNG 图片版报告（中文图表）

### 指标口径

| 指标 | 公式 |
|---|---|
| 销售额 | Σ实付金额（剔除退款） |
| 订单量 | 非退款订单数（按订单号去重） |
| 客单价 | 销售额 ÷ 订单量 |
| 退款率 | 退款订单数 ÷ 总订单数 |
| 毛利 | 销售额 − Σ(成本价×数量) |
| 毛利率 | 毛利 ÷ 销售额 |

## 🌐 部署上线（简历展示用）

推荐 Streamlit Community Cloud（免费，含公网链接）：

1. 注册 GitHub 并创建公开仓库，上传本项目（`data/user/` 与 `data/demo/raw/` 已被 `.gitignore` 排除）
2. 打开 https://share.streamlit.io ，用 GitHub 登录
3. "New app" → 选择仓库与分支，Main file 填 `app.py`，点击 Deploy
4. 数分钟后获得公网链接（如 `https://xxx.streamlit.app`），可写入简历

> 提示：云端主要用于功能演示；真实经营数据请在本机使用，避免敏感数据上传。
